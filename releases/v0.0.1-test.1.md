## 🎯 Release summary

This ZIP is essentially a deployment and release framework for your Controlplane Platform. It does not yet contain the Grafana/Prometheus/Loki management platform or web UI. Its job is to create a clean Ubuntu controlplane environment on either Proxmox LXC or Windows WSL, configure the operating system, validate the project, and manage releases.

## ⚡ One-line installation

### Proxmox VE

```bash
curl -fsSL https://raw.githubusercontent.com/Fouchger/Homelab/test/install-proxmox.sh | bash -s -- --release v0.0.1-test.1
```

### Windows WSL

```powershell
& ([scriptblock]::Create((Invoke-RestMethod 'https://raw.githubusercontent.com/Fouchger/Homelab/test/install-wsl.ps1'))) -Release 'v0.0.1-test.1'
```
