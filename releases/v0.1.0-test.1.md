## 🎯 Release summary

Introduce the Phase 2 Controlplane web application and CI validation. Adds a new Django app (controlplane_app) with models, migrations, views, forms, templates, static assets, security (TOTP, encrypted secrets, recovery codes), services for releases/upgrades and email, middleware, management worker, tests and URL routes. Update controlplane_web settings, pyproject (v0.2.0) and pinned dependencies (cryptography, qrcode). Adjust release packaging to copy the full web directory. Add Proxmox extension changes to enable background worker, certificate bootstrap endpoint, runtime dirs and service units. Add docs (docs/phase2.md), required-files and unit tests, and a GitHub Actions job to run Django checks and Phase 2 tests against PostgreSQL.
