## 🎯 Release summary

Introduce Phase 1 web platform for Controlplane: adds a minimal Django app (under_construction, /health, /ready), packaging and pyproject for controlplane-web, and a stable-versions.env pinning tested runtime versions. Add ordered Proxmox extension scripts (10-70) to install uv/Python, local PostgreSQL, Gunicorn service, app deployment, Nginx, security (bootstrap TLS) and final validation. Add container helper, packaging/release updates to include runtime files, docs (phase1.md), changelog/README updates, validation list, and unit/release tests to verify Phase 1 assets.
