## 🎯 Release summary

Controlplane Platform v0.1.0 delivers the completed Phase 2 web application, introducing secure first-run administrator setup with mandatory MFA, user and invitation management, personal appearance preferences, administrator-only system configuration, Gmail and Microsoft email provider support, controlled release management with background upgrades and rollback safeguards, structured operational history, improved certificate onboarding, hardened version calculation, and a more polished and compact user interface. This release has been validated on the existing Proxmox Controlplane LXC, with Gmail email delivery manually tested successfully and all core platform health, readiness, authentication, upgrade, packaging and release-process checks passing.

## ⚡ One-line installation

### Proxmox VE

```bash
curl -fsSL https://raw.githubusercontent.com/Fouchger/Homelab/main/install-proxmox.sh | bash -s -- --release v0.1.0
```

### Windows WSL

```powershell
& ([scriptblock]::Create((Invoke-RestMethod 'https://raw.githubusercontent.com/Fouchger/Homelab/main/install-wsl.ps1'))) -Release 'v0.1.0'
```
