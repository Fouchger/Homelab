## 🎯 Release summary

This release completes the Phase 2 Controlplane web application, including first-run administrator setup, mandatory MFA enrolment and verification, recovery codes, secure login/logout, Administrator and User roles, invitation-based user onboarding, user management with MFA and invitation status, personal appearance preferences with the full agreed theme set, administrator-only system Configuration for Email and Releases, Gmail/Microsoft 365/SMTP support, controlled release upgrades with background progress and rollback safeguards, structured History with date filtering and execution-step detail, Windows certificate installation guidance, improved installer completion messaging, and the Under Construction dashboard for normal post-login access.
