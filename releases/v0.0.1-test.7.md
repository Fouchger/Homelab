## 🎯 Release summary

Grant the nginx service account membership in the controlplane group and validate Unix-socket access as the nginx identity. Add bounded readiness loops and diagnostic output for Gunicorn and Nginx startup failures, and validate the Gunicorn backend via its Unix socket before configuring the proxy. Minor safety changes to heredoc delimiters and service start ordering. Update health/validation checks and unit tests accordingly, and record the change in the changelog.
