## 🎯 Release summary

This release improves Controlplane email configuration by aligning Gmail, Outlook.com/Hotmail, Microsoft 365/Exchange Online, and Other SMTP setup with current official provider guidance, adding clear provider-specific instructions, required authentication details, server/port/security presets, verification steps, and links to official documentation. It also clarifies when external setup is required, keeps Gmail simple with App Password support, uses OAuth2/Modern Auth for Microsoft services, and improves the administrator experience by explaining exactly what is needed before email invitations can be enabled.
