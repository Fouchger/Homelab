## 🎯 Release summary

This test release updates the Controlplane release-note generator so future GitHub releases produce clear, professional and auditable documentation automatically. Test releases now describe only the incremental changes introduced by that build, while stable releases generate a complete product-level summary of the functionality delivered since the previous stable release. Empty change categories are removed, release content is grouped into meaningful sections, promoted test candidates are identified, runtime assets and checksums are listed explicitly, and release assurance records the tested source and promotion state. Additional regression tests have been added to prevent the generator from returning to the previous commit-oriented release-note format.
