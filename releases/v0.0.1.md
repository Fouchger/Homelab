## 🎯 Release summary

This release delivers the first complete Phase 1 implementation of the Controlplane Platform, extending the existing Proxmox LXC deployment process into a working webserver foundation while preserving the established tag-first discovery, reuse and replace behaviour for existing Controlplane containers. It adds Python 3.14 managed through uv, local PostgreSQL 18, Gunicorn, a minimal Django application with an Under Construction page plus health and readiness endpoints, Nginx with HTTPS, security hardening and final platform validation. The release also strengthens post-install failure detection, ensures existing tagged Controlplane LXCs can be reused without recreation, and corrects runtime version validation so provisioning can continue reliably through the full Phase 1 installation sequence.

## ⚡ One-line installation

### Proxmox VE

```bash
curl -fsSL https://raw.githubusercontent.com/Fouchger/Homelab/main/install-proxmox.sh | bash -s -- --release v0.0.1
```

### Windows WSL

```powershell
& ([scriptblock]::Create((Invoke-RestMethod 'https://raw.githubusercontent.com/Fouchger/Homelab/main/install-wsl.ps1'))) -Release 'v0.0.1'
```
