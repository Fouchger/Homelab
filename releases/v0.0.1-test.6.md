## 🎯 Release summary

Select the latest managed Python 3.14.x from uv's frozen catalogue and update uv to 0.12.3. Updated CHANGELOG and config/tooling/stable-versions.env (PYTHON_VERSION=3.14, UV_VERSION=0.12.3). Runtime scripts (10-web-runtime.sh, 31-webapp.sh, 70-validation.sh) now install/validate a managed 3.14.x interpreter and force venv creation against the managed runtime. Unit tests adjusted to assert the new pins and to check for the managed-python usage.

## ⚡ One-line installation

### Proxmox VE

```bash

```

### Windows WSL

```powershell
& ([scriptblock]::Create((Invoke-RestMethod 'https://raw.githubusercontent.com/Fouchger/Homelab/test/install-wsl.ps1'))) -Release 'v0.0.1-test.6'
```
