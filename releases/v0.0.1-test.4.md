## 🎯 Release summary

Replace uses of `uv --version` with the metadata-free `uv -V` and add a runtime verification that exits with a clear error if the installed uv version doesn't match. Update the validation script to use `-V` and extend unit tests to enforce `-V` usage and fail if `--version` is present (since `--version` can include build metadata and break exact equality checks).
