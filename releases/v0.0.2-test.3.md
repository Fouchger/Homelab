## 🎯 Release summary

Split Microsoft email provider into personal Outlook.com/Hotmail and Microsoft 365/Exchange Online. Add DB migration and model field for encrypted Microsoft refresh tokens. Implement personal Outlook OAuth: authorization URL, token exchange, refresh handling, and integrate with SMTP send logic. Update forms, views, URLs and templates to support connect/callback flow and validation; preserve secret handling and reset refresh tokens when client ID/provider changes. Update docs, README and changelog. Add unit tests for email behavior and a release workflow test; make release workflow run-name and final summary show DRY RUN vs PUBLISH.
