## 🎯 Release summary

When reusing existing LXCs, stop forcing exact tested patch installs which could downgrade a healthy newer stable patch. Introduce POSTGRESQL_MINIMUM_TESTED_VERSION and NGINX_MINIMUM_TESTED_VERSION, install by major/package name, and validate installed versions with dpkg --compare-versions. Update scripts (20-controlplane-postgresql.sh, 40-nginx.sh), tests (phase1_test.sh), stable-versions.env, and CHANGELOG to reflect the new minimum-tested semantics and the PostgreSQL minimum bump to 18.6. Ensures reuse retains newer stable patches while enforcing tested minimums.
